# 《雪夜旅馆》项目上下文

更新时间：2026-10-15。本文用于新任务恢复长期共识；实现现状以源码和当前工作树为准，具体历史见 `开发记录.md`。建议与已确认决定分开记录，行为变化完成后同步更新。

## 产品与技术

中文离线叙事探索游戏，以雪夜旅馆、不断绕回的林路、线索调查和人物说法之间的矛盾展开。采用 TypeScript、Vite、原生 DOM 与 Tauri 2；无运行时服务端、远程素材或云存档。先验证网页前端，再按交付需要导出 Windows NSIS，不引入 Unity/Godot。

已发布的首轮试玩工程版本为 `0.1.0`。目前处于“游戏 2.0”开发阶段；产品阶段名不等于软件包版本号，现有 package.json 与 Tauri 仍为 0.1.0。第 19 步安装包属于开发验证，未作为 2.0 正式发布。不要根据本文假定当前改动已提交或上传，开始工作时检查 Git。

## 玩家反馈与 2.0 目标

首轮反馈：重复循环较多、伏笔作用不明确、故事平淡且奇异感不足、体验不同结局需要重开。2.0 已获授权扩展场景和剧情，补充可重玩的存档能力，并用环境画面帮助玩家掌握空间。

设计目标：异常能够被观察或检验，线索影响追问和理解，人物说法与实际证据可以矛盾；减少无变化的重复操作；保持新场景与现有场景的连接。

## 已确认并实现的方向

- **旅馆外观**：一直不进入时，旅馆逐渐衰老、呈现年代变化；树林等周围环境保持连续。进入后的室内与先前外观构成矛盾；多次观察后可连续赶路减少点击。
- **隔壁半杯水**：先观察再提供喝水选择。房间表达“没有直接看见有人”，不能据此宣告从未有人住过或无人承认住过。
- **第一夜厨房**：恢复原设计里的野猪和制作香肠情节。早餐颜色/入口味道更像鹿肉，玩家可按实际所见所尝追问。
- **旧宴会厅**：新增场景通过一楼走廊双开门与厨房侧门连通，夜间关闭、白天探索；杯印、椅脚痕迹和片段话语提供线索。
- **地下室对话**：身份未明的残缺话语，不直接揭示人物身份。前台说法不是唯一结论。
- **存档与回溯**：每次选择后自动保存；三个手动档；当前旅程关键节点回溯；读取或回溯前归档当前旅程；历史归档供回看。保留旧版兼容、坏档拒绝、保存失败与其他窗口更新提示。
- **场景美术**：31 张本地 WebP（保留原 12 张，2026-10-08 新增 19 张；2026-10-29 由 PNG 转为 WebP，体积 85.7MB→8.5MB），低饱和全彩，云杉林、雪、灰石和旧木，中世纪城堡内饰参考。新增夜间门前近景、有人前台、两幅画像与登记簿/合影/早餐特写，室外昼夜、第一夜暗长廊及邻房、厨房人物与清晨、宴会厅杯印拖痕、肉墙和水下图。前台人物按剧情在场条件显示，线索特写仅在对应调查节点显示，可放大观察。
- **场景主导交互**：2026-10-13 已实现持续图片舞台，覆盖当前82个剧情节点，并按用户纠正改为图面浮字和靠近展开。旁白没有独立卡片，按桌面90字/窄屏60字上限、句末优先逐段浮现，全部正文可前后翻阅；缩放保留阅读位置，视图切换取消旧分页监听。室内楷体、室外/水下宋体倾向，使用本机离线字体，字色/字距/阴影随环境变化。门、人物及物件轻标记靠近120ms后在旁展开作者原文，离开300ms后收起；点击标记仅展开，选原文才执行。未画对象使用标明方向/画外/当前决定的边缘入口，窄屏同样保留图面锚点，触屏/键盘可展开。换景、调查、对话、返回、结局仍区分呈现，支持立即显示、减少动画和图片失败文字退化；动画和分页不写存档，实际选择仍走既有规则。网页最终效果仍需在恢复预览访问权限后检查，见本轮任务。
- **现有结局与谜题**：离开旅馆外林路、溺亡、退房、成为前台四个结局。衣柜是 20 根绳、40 个可移动端点的环形绳阵，完成条件为零交叉；井绳等局部解谜仍由代码绘制。
- **行动浮层与标记**：2026-10-14 按用户截图反馈改为半透明大圆角行动胶囊，移除整体硬边弹窗底板，单行动隐藏可见标题栏，44px关闭区保留。常态底色不透明度约53–59%，按五种环境色调变化；保持静止、靠近展开、选择作者原文才执行。新增27款本地细线SVG，灯光用提灯、门用门框、画像用相框、登记簿用书册，移除统一文本箭头。图标只概括当前具名入口，不推断未知物件。源码及自动化完成，真实网页视觉仍待验。
- **图标横向展开**：同日按第二张截图纠正展开位置，改为图标同位起点、行动文字在同一连续横条中伸出；右侧空间不足翻向左，取消避让旁白后上下另起菜单的位置策略。原标记短标签和图形在展开时隐藏，保留连接DOM供焦点返回。短行动自然收紧、多行动横向浏览、原文按实际行动区宽度换行；两端按钮44px，裁切揭示动画不拉伸SVG。点击起点/关闭或Esc收起，仍只点击完整原文执行。
- **旁白自动避让与短句宽度**：同日按687×668截图及补充要求修正。短行动测量保留小数、向上取整并留余量，有空间时保持单行。旁白按当前图面与视口自动避开标记、标签、展开条和导航，标记仍固定在对应物件处；安全旧位置优先，展开、翻页与缩放时重新计算。没有可读空位时浮字隐藏，导航提供“阅读旁白”入口；打开后保留全部正文、当前页、道具反馈、井绳示意与结局行动，关闭恢复原位置和可见控件焦点。只影响显示，不修改剧情、存档和素材。

- **阅读连续性与键盘保护**：2026-10-15旁白增加只在内存保留的单场景书签，查看物品、存档或日记再返回会恢复字符位置和收起状态，反复缩放不会逐次退回页首；主动翻页才更新字符锚点。新旅程、节点或正文变化重置书签，不增加存档字段。行动条不会被无意悬停替换含焦点菜单，显式激活仍可切换；放大图前关闭行动条及悬停计时，舞台Esc尊重已消费按键与顶层原生modal。

  │

前台大厅
  ├─ 楼梯 ─ 二楼长廊 ─ 你的客房 / 隔壁客房（衣柜绳阵、半杯水）

## 待评估事项（不是已承诺实施）

- **多窗口交错保存**：2026-10-15只读检查用内存存储复现比对与写入之间的竞态；已有保护仅能拒绝检测到的串行更新，两个窗口同一瞬间写入仍可能静默覆盖。后续需设计同源写入独占与异步保存反馈，验收交错写、锁等待的新进度及失败重试。现阶段同一进度使用单窗口，不把它列为已修复功能。
