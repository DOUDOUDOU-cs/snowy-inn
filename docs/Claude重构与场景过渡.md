## 过渡时序与演出约定

源码入口为 `main.ts:125` 的 renderStory 与 `sceneView.ts:323` 的 present：

1. beginView 取消旧异步、递增 viewEpoch、关闭井谜题弹窗。主层结合状态快照与已行动标记拒绝旧回调/重复选择。
2. 根据 space、mode、scene 分类为 move / inspect / return / dialogue / ending。这些分类没有全部对应独立演出，不能宣称五套动画已完成。
3. 舞台再次取消旧轮次，新建 AbortController，进入 loading；先准备布局和分页，移除旧正文与热区。
4. 已完整加载的同图直接复用；异图先加载、decode，最多等待 8 秒。底图保留，新图进入上层 scene-art-buffer。
5. 缓冲层透明度从 0 到 1 覆盖底图，CSS 为 420ms ease；JS 对 move 等待 420ms，其余异图等待 240ms，再更新底图并隐藏缓冲。
6. 图片到位后更新替代文字、模糊背景，生成热区与正文并进入 ready。新空间有约 1.6 秒发现微光，1.7 秒后清理标记。
7. 旁白每页透明度＋上移 6px，持续 560ms；末页选项 420ms；暖光悬停 260ms，标签约 200ms。全局样式和 JS 共同处理减少动态偏好。

整体为静态图交叉淡入、柔化边缘与文字后入场，没有镜头移动、缩放或视频演出。继承“图片到位再放出行动、同图复用、取消旧轮次”，不为每个按钮另加动画。

失败或超时后主图隐藏、picture=missing，仍提供正文与合法行动。进入系统页会取消旧过渡，防止加载完成后覆盖新页面。

## 应保留的交互

- 固定 3:2 画框，百分比热区；不恢复 JS 测量和观察器驱动的自动避让。
- 桌面单动作点击物件直接执行，多动作开就近菜单；触屏先菜单预览，防止误触推进。
- 画外去处用左右边缘箭头；交谈和决定读完旁白后显示，不恢复统一胶囊。
- 暖光依附物件；旁白无框、文字下方柔和阴影；画框外用当前图的暗化模糊延伸。
- 空白/空格继续、方向键回看、数字键选末页选项、Esc 关菜单、H 隐藏/恢复；dialog 打开时不抢输入。
- 阅读书签留在内存，按旅程、节点与正文识别，物品页返回恢复段落，不改剧情存档格式。

## 本轮记录、不顺手修的风险

- 特写等异图 240ms 后隐藏缓冲，而 CSS 淡入为 420ms，可能截断末段；后续先观察特写进出再确定是否统一时长。
- 旧发现微光的 sleep.then 在取消后仍可能删除共享 is-discovering，影响同图快速切换的新轮次提示；尚未浏览器复现。
- 隐藏 HUD 后，子元素仍有 pointer-events:auto；透明按钮是否可点/聚焦需定向验收。
- 老化过滤仅覆盖底图，缓冲层可能产生明暗跳变；待需要修改老化演出时观察。
- 当前单例无需重复清理全局监听；未来若多次创建舞台，需要 dispose，不能复制创建调用。

以上为源码风险，不等于实际画面必然出错；不因此新增通用动画框架或扩大本轮实现。
