# 场景交互重做（开场原型）

状态：原型已获用户确认，后续推广见 2026-11-03 任务
更新日期：2026-11-03

## 目标与依据
- 玩家要解决的问题：用户试玩后认为原交互“反人类”——先找小图标、悬停或点击展开胶囊、再点文字才执行，每个动作两步，点的始终是 UI 而不是场景；旁白靠 JS 计算避让，位置漂移。
- 用户已确认需求：旁白“自然浮现在场景上方，位置不做要求，唯一标准是自然，字体可适当减小”；先做开场原型，确认手感后再铺开到全部节点。
- 本轮范围：替换整个场景舞台（所有节点同时使用新交互），按实图校准开场路线坐标；其余场景沿用旧锚点与默认范围。

## 验收标准
- [x] 画中物件直接点击：悬停照亮并显示动作，单动作一次点击执行，多动作弹出就近菜单。
- [x] 画外去处为左右边缘箭头；交谈话题与决定在读完旁白后列为文字选项，可用数字键。
- [x] 旁白无框浮现、可读；点击空白/空格/回车翻页，← → 回看；返回物品页后保留阅读段落。
- [x] 每个节点的每个可用选择恰好呈现一次（自动测试覆盖全部节点与多种状态）。
- [x] 桌面 1280×800 与手机 390×844（触屏）实测：开场路线、多动作菜单、文字选项、物品页往返、结局。
- [x] 用户试玩确认手感（2026-11-03 明确表示满意 Claude 已完成效果，授权继续推广）。
- [x] 其余场景（客房、走廊、厨房、宴会厅、地下室等）逐图校准坐标与可点范围；实现及验收记录移交 [11-03 推广任务](2026-11-03-场景交互全面推广.md)。

## 决策与假设
- 画面固定 3:2 画框（所有场景图均为 1536×1024），热区用 CSS 百分比定位，不再用 JS 测量、ResizeObserver 或 MutationObserver。
- 旁白放在非出口热区较少的一侧；脚下的路不推开文字。
- 触屏没有悬停，轻点先弹出动作菜单再执行，避免误触直接推进剧情。
- 删除旧 `sceneStage.ts`、`narrationLayout.ts`、`sceneIcons.ts` 及其只覆盖内部实现的测试；剧情、规则、存档结构与谜题入口不变。
