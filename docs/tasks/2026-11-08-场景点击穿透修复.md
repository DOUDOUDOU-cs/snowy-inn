# 场景点击穿透修复（旁白 / 隐藏文字）

状态：已完成
更新日期：2026-11-08

## 目标与依据

- 玩家要解决的问题：点击旁白正文会直接执行下方出口动作；按 H 隐藏文字后，不可见选项、继续按钮、物品按钮仍可点击，数字键仍可选项，会静默推进剧情并写入自动存档。
- 用户已确认需求：修复两处点击穿透，不改变剧情、存档格式、美术与场景坐标；修复后由主 agent 完成集中测试与真实主入口浏览器验收，再交独立复核（T1，6.1 Sol @ high，约 15 分钟）。
- 相关源码：`src/ui/sceneLayout.ts`（旁白分区、热区布局）、`src/ui/sceneView.ts`（点击/按键/隐藏）、`src/ui/sceneView.css`、`src/main.ts`（HUD）。
- 依据证据：`.scratch/recheck/report.json` 与 01–22 截图（真实主入口复现）；`.scratch/review-ux/`（首轮实测）。
- 本轮范围：只修这两处交互与对应最小测试；`main.ts` 编排拆分、flag schema、存档竞态、release 重建不在本轮。

## 验收标准

- [x] 点击旁白区域（含末页）只翻页，不执行任何热区动作、不改变场景与存档。
- [x] 旁白位置按所有热区（含画中出口热区）计算，尽量不覆盖可点物件；如仍有重叠，动作必须仍可从画面暴露区域或文字选项到达。
- [x] H 隐藏文字后：文字层与 HUD 不可点击、不可 Tab 聚焦；数字键/方向键/空格不推进剧情；点击画面任意处恢复文字，恢复后一切正常。
- [x] 390×844 窄屏图文上下布局不受影响；原有悬停、菜单、Esc、系统页返回原页不回归。
- [x] 集中测试一次（相关文件）与网页构建一次通过；真实主入口 CDP 桌面 + 窄屏验收留证。
