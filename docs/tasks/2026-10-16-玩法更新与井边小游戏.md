# 玩法更新与井边小游戏

状态：计划已确定，实施中
更新日期：2026-10-16

## 目标与依据
- 用户要求以游戏设计师视角自主判断、列计划、分派子agent实现并测试。选择能沿用当前空间、线索和存档的玩法，避免只堆无关小游戏。
- 当前井绳流程只需连续点唯一的向前选项，缺少观察与试错；绳阵有40可移动端点、选中高亮及交叉总数，但缺少可逆尝试和移动效果反馈。
- 本轮实施：井边自由部件操作小游戏；绳阵未完成时撤销与交叉变化反馈。维持四结局、钥匙来源与门锁条件，不改存档结构。
- 证据追问列为后续最小切片；宴会厅座次/时间复原不实施，现有杯印和拖痕不能唯一推出座次或说话人，需先补可观察新线索。

## 玩法方案
### 井边轱辘
- 原图作背景，在真实井绳、绳槽、握绳位置、摇柄、桶的位置提供可操作入口；允许直接尝试多个部件，不按正确步骤排列按钮。
- 错误操作给出具体物理反馈，不推进、不扣物品、不限时；线索提示允许逐级查看。上槽→握稳→转动两次→提桶沿用现有剧情动作。
- 只有原规则允许的步骤才通过recordChoice/commitRecords推进；钥匙只在实际提桶后获得一次。退出保留已完成步骤，旧档任一rope节点可恢复；井边原文字路径保留。
### 绳阵改良
- 保留40端点和零交叉条件，不自动解题。显示本次调整后交叉数量变化，可比较尝试的效果，不宣称每步必须减少交叉。
- 增加本次打开期间、尚未完成时的撤销，逆操作仍调用原保存入口；已完成和拿走钥匙后不可回退，不改变引擎的完成规则。
- 提供选中绳相关交叉信息或等价局部反馈；已有高亮与全局计数不计作新增成果。

## 井边接口（先确定再并行）
- `WellInteraction = rope | groove | grip | crank | bucket`。
- `WellPuzzleView = { stage: 0|1|2|3|4|5; title: string; description: string; hint: string; textAction?: {interaction: WellInteraction; label: string} }`；0对应ropeSlips，依次ropeOnWindlass/ropeWrapped/ropeWoundOnce/ropeWoundTwice，5为silverKey且实际已持钥匙。textAction取原getScene下一步作者原文，文字退化也调用同一操作接口。
- `wellPuzzleView(GameState): WellPuzzleView|null`只读当前节点，`wellPuzzleAction(GameState, interaction): {choiceId?: string; feedback: string}`只提出合法原动作，不自行写状态。
- UI导出`openWellPuzzle(initial: WellPuzzleView, art: SceneArt, onInteract: (interaction: WellInteraction) => {view: WellPuzzleView; feedback: string; warning?: string}|null, onClose: () => void, initialWarning?: string): void`。回调返回null说明视图已过期，关闭，不执行旧动作。UI关闭一次、键盘/触屏可用、不向本地存储直接写入。第5参数确保首次pull-rope保存失败时立即可见，不等下一次操作。
- 主界面从pull-rope以及旧rope流程的下一步动作进入；已在井边打开时，各次操作都重新读当前可用选择并提交。关闭重绘最新节点，旧epoch/旅程不可回调。打开、错误尝试、提示、退出不产生额外剧情记录。

## 验收标准
- [ ] 可从正常投戒指→过夜→拉井绳进入新小游戏；旧rope节点可继续，原文字路径仍可达。
- [ ] 乱点不发钥匙、不跨步骤；完整操作只获一次银钥匙，步骤可保存/恢复，取消/旧回调不推进。
- [ ] 井边原图空间与控件对应，桌面/触屏/键盘有明确反馈，最小44px目标；无计时或不可逆失败。
- [ ] 绳阵撤销恢复确切前序排列，实际走保存规则；完成后不可撤销，交叉变化准确，20绳/40端点/零交叉不变。
- [ ] 全部原116项测试及新增具体风险检查、网页构建通过；修复独立审计问题。
- [ ] 同步说明与开发记录，准确标记真实网页验证范围，不以最小DOM代替视觉验收。

## 后续玩法路线（未实施）
1. **证据追问，小范围试做**：先只做早餐。玩家从实际获得的“昨夜所见”和“今晨观察/品尝”中选取两条见闻，组织一条有依据的追问，沿用kitchenQuestion回应。只有亲自听到‘准备明早早餐’才能引用该说法；肉色/味道相似不等于鉴定肉种。先保留直接追问，不新增强制通关门槛。
2. **宴会厅局部痕迹对照，补证据后再做**：现有线索不足以推出座次或事件时序，‘坐得很晚’和椅子被挪过也不必然矛盾。若增加谜题，应先有可见椅脚缺口、对应短划/灰尘边界等新约束，只复原物件移动，不揭示匿名声音身份；图文要同时更新。
3. **暂不加入**：限时逃脱、随机惊吓QTE、与剧情无关的数独/密码锁。它们会增加操作负担，难以补足本作的观察、检验和线索回收。
