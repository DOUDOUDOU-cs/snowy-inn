# 《雪夜旅馆》0.1.0 试玩版

## 启动方式

优先使用发布页中的 Windows 安装程序。安装完成后，从开始菜单或桌面快捷方式启动《雪夜旅馆》即可，不需要另行安装 Node.js、Rust、Vite 或 Tauri。

如果使用便携版，先完整解压 ZIP，再双击 `雪夜旅馆.exe` 即可启动。

## 当前内容

- 一条完整的旅馆探索主线。
- 四个可达结局。
- 第一人称日记记录。
- 碎木屑、井绳和四十端点环形绳阵三类互动解谜。
- 自动保存与继续游戏。

## 已知限制

- 当前场景背景和部分视觉素材是原型资源，后续版本会整体重构。
- 本版本主要验证剧情、状态流转、结局条件与小游戏逻辑。
- 安装程序尚未进行商业代码签名，部分 Windows 电脑可能显示“未知发布者”。

## 开发者启动

```powershell
npm install
npm run tauri dev
```

## 验证与导出

```powershell
npm test
npm run tauri build
```
