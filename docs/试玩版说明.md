# 《雪夜旅馆》0.2.0 试玩版

## 启动方式

优先使用发布页中的 Windows 安装程序。安装完成后，从开始菜单或桌面快捷方式启动《雪夜旅馆》即可，不需要另行安装 Node.js、Rust、Vite 或 Tauri。

如果使用便携版，先完整解压 ZIP，再双击 `雪夜旅馆.exe` 即可启动。

## 当前内容

- 一条完整的旅馆探索主线与四个可达结局。
- 28 张随包分发的本地 WebP 场景图（原 31 张中移出 3 张未引用素材），完全离线运行。
- 第一人称日记；自动保存、三个手动存档位与关键节点回溯。
- 碎木屑、井绳与四十端点环形绳阵三类互动解谜。
- 画面中的门、人物和物件可直接点击；旁白浮现在画面上，按 H 可只看画面。

## 已知限制

- 安装程序尚未进行商业代码签名，部分 Windows 电脑可能显示“未知发布者”，或被 SmartScreen 拦截；选择“更多信息 → 仍要运行”即可。
- 字体使用本机字体；没有云同步与存档导入导出。
- 静态场景图为主，尚无场景间视频或分层动画。

## 开发者启动

```powershell
npm install
npm run tauri dev
```

## 验证与导出

```powershell
npm test
npm run tauri build
```
