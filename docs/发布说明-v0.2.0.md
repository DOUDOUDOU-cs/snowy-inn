# 《雪夜旅馆》0.2.0 试玩版

发布日期：2026-11-09

第二轮开发（0.2.0）交付。在 0.1.0 试玩版基础上，补齐 19 张场景图、四个结局的可达路径、三档手动存档与关键节点回溯、第一人称日记，并重做点击式场景交互。

## 本版内容

- 完整旅馆探索主线与四个结局：离开森林、水下的寂静、写下退房日期、坐上前台。
- 28 张随包本地 WebP 场景图，完全离线；森林、遗迹、水井、前台、客房、长廊、厨房、宴会厅、地下室等场景含昼夜或状态变化。
- 场景图即操作界面：画中物件点击、悬停暖光、多动作就近菜单、画外边缘出口；旁白浮字，支持鼠标、键盘与触屏。
- 解谜：碎木拾取、井绳轱辘、衣柜 20 根绳 / 40 个端点的环形绳阵（零交叉）。
- 记录：每次选择自动保存、三个手动存档位、六个关键节点回溯、旅程日记；兼容旧版记录并拒绝损坏存档。
- 按 H 可只看画面；隐藏时文字与画面按钮都不再响应点击。

## 0.2.0 修复与改进

- 修复点击旁白会误触发画面出口的问题；旁白位置现在会把画中出口热区一起避开。
- 修复隐藏文字后不可见按钮仍响应鼠标/数字键的问题；隐藏态文字与画面按钮均不可交互、不可 Tab 聚焦。
- 390px 窄屏 HUD 改为两行布局，长地点名与持物数量不再折行。
- Tauri 配置显式化（CSP、关闭 withGlobalTauri、窗口最小尺寸），移除模板残留依赖。
- 清理 3 张未引用场景图，安装包体积约 8.6MB。

## 下载与安装

- 安装版：下载 `snowy-inn-v0.2.0-windows-x64-setup.exe`，双击安装，从开始菜单或桌面快捷方式启动。
- 便携版：下载 `snowy-inn-v0.2.0-windows-x64-portable.zip`，完整解压后双击 `雪夜旅馆.exe`。
- 系统：Windows 10/11 x64；不需要 Node.js、Rust、Vite 或联网。
- 安装程序尚未商业代码签名，首次运行可能被 Windows SmartScreen 拦截：选择“更多信息 → 仍要运行”。

## 已知限制

- 未做商业代码签名；无云同步、存档导入导出。
- 静态场景图为主，暂无场景间视频或分层动画；部分细小状态差异以正文为准。
- 字体使用本机字体。
