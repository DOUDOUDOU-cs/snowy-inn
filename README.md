# 雪夜旅馆

一款以文字、选项和调查为核心的离线叙事游戏，使用 TypeScript、Vite 和 Tauri 2。

## 目前可以玩什么

目前可以从雪夜开场玩到四个结局：连续赶路离开森林、地下室溺水、查明旅馆后填写退房日期，以及逐渐融入旅馆后坐到前台回应新旅人。途中可以调查村庄遗迹、画像与戒指、水井、客房、隔壁房间、夜间厨房、旧宴会厅、前台锁柜和地下室。

遗迹中调查碎木下的亮点时，会从画面中央打开局部解谜界面。依次拨开压住下层的木条，再点击露出的戒指才能拾取；可关闭或按 Esc 返回，未拾取时不会推进剧情或获得物品。木条当前用 CSS 绘制，退出后再次打开会从未拨开的状态开始。

第一夜后调查隔壁衣柜，会看到古铜色钥匙被二十根交错的旧绳挡住。中央弹窗是一圈带有 40 个活动端点的旧木圆框，每根绳的两端使用相同编号；圆周上的任意端点都能拖动或与另一端点交换，方向键可沿圆周移动一格。选中端点时会突出整根绳与它的另一端，并压暗其他绳线；界面同时显示剩余交叉数。圆内完全没有交叉后才能领取钥匙，允许多种解法。每次交换都会自动保存，关闭弹窗或退出游戏后可继续。绳线使用低饱和的旧织物色调，圆框与绳线目前均由本地代码绘制，后续可换成正式场景素材。

从未进入旅馆时，坚持赶路会看见旅馆外观逐渐衰老；察觉几次变化后，可直接选择一直走到森林尽头。若已经进过旅馆，再沿来路走，路上的细节会改变，走得够远也只会绕回门前；重复尝试几次后，主角会意识到这条路走不通，继续赶路的选项随之消失。这条路线不会显示次数。

点击右上角“随身物品”可以查看物品与已知线索，再回到原场景；“旅程记录”以第一人称日记回顾关键发现与决定。“存档／回溯”可使用三个手动存档位，也可从走过的关键分岔重新选择。返回标题后可以继续本次探索；“重新开始”会先提示，并把当前旅程收进历史记录。

## 静态场景图

游戏已加入低饱和全彩场景图，随包素材 28 张（原 31 张；2026-11-09 移出 3 张无源码引用的旧图，约 0.87MiB）。旅馆门前的夜间近景与走进大厅后的接待画面分开；前台小姐是否在柜台后随剧情切换。调查柜台肖像、遗迹全家福、登记簿、锁柜合影和早餐时，会显示对应特写，返回后恢复环境图。树林、井边和遗迹有对应的昼夜画面；第一夜长廊与隔壁房内的灯光、厨房夜间制作香肠与清晨擦净台面、宴会厅木地板杯印拖痕、地下肉墙与水下也有相应画面。外景衰老仍随剧情切换，清晨门前沿用森林晨间视角。

场景图就是操作界面。画中的门、人物和物件可以直接点：鼠标移上去，那样东西会像被提灯照亮一样微微发亮，并显示它能做什么（只有一个动作时直接写出动作，如“进入旅馆”）；点一下就执行。同一物件有几个动作时，点它会在旁边弹出一个小菜单。画面里看不见的去处（如“村庄遗迹”“旅馆外”）是画面左右两侧的淡色箭头。进入一个新地点时，可互动的东西会轻轻亮一下提示位置。

旁白不放在对话框里，而是浮现在画面上方或下方较空的一侧，用暗影衬托，不加边框。点击旁白本身或画面空白处、按空格或回车翻到下一段，← → 键可前后翻阅；旁白位置会把画中的出口热区一起避开，必要时移到上/下的一侧，不会压住可点物件。与人交谈的话题、需要做的决定，会在旁白读完后列在文字下方，可直接点击或按数字键选择。室内采用楷体倾向，室外和水下采用宋体倾向，文字颜色与阴影随环境变化；字体使用本机字体，离线可用。

右上角的“物品”“日记”“存档”“标题”是系统入口；“隐藏文字”（或按 H）可以只看画面，此时文字层与菜单不再响应点击或数字键，点击任意处恢复。窄屏和手机上图片在上、文字在下；触屏没有悬停，可互动的东西会缓慢呼吸发光，轻点会先弹出它的动作再确认执行。图片暂时无法显示时，仍可通过文字选项继续。

查看物品、存档或旅程记录后返回同一场景，会回到旁白正在读的那一段；进入其他剧情节点或读取另一旅程会从头阅读。

当前过场使用图片淡入，尚未加入场景间的视频或分层动画。静态画面仍不能逐次表现喝水后的细小水位等物件变化，具体线索和动作结果以正文为准。

场景图均是随游戏安装的本地 WebP 文件，离线可用。28 张图片保持 1536×1024，素材体积约 7.3MB。客房、昼夜长廊和邻房、厨房、宴会厅、地下室的门、家具和物件均已按实图校准点击范围；画面里无法定位的声音和水道洞口继续通过文字选项调查。图像生成方式、提示词组合及每张图与场景的对应关系见[场景图生成记录](docs/场景图生成记录.md)。

在自己的客房里，点击左侧房门即可查看当前可去的地方；去走廊、下楼或离开旅馆等去向会随剧情列在同一个菜单里。

登记簿可以在入住前后反复查看；隔壁客房的半杯水可以观察与品尝。第一夜可循楼下的声音走进厨房，看见前台小姐处理野猪；睡醒后，可以接受、假装吃或谢绝早餐，并检验昨夜所见与今晨味道的矛盾。厨房旁的旧宴会厅白天可以进入，从侧门与厨房相通。古铜色钥匙可打开前台锁柜；银白色钥匙需先在井边处理湿滑井绳、架到轱辘上、缠绕绳子，再转动轱辘取出。井边目前使用简易贴图和动画，后续可重构场景。地下室沿墙调查能听见身份不明的残缺对话，并带回线索追问前台。戒指、画像、合影与旧账本会改变部分对话，但不会阻止退房。跳入水道洞口时，前台小姐最多会救你一次；再次跳入不会重复获救。获救后若已经感到旅馆像家，可以决定再多住一晚，走向另一种结局。

## 旅程记录与自动保存

- 每次选择后自动保存当前场景、物品、线索和剧情进展；查看物品获得的新线索也会保存。刷新页面或关闭后重新打开，可以从标题页继续。
- 三个手动存档位可在探索中保存、覆盖或读取，包括达成结局后读取。读取会把当前旅程归档，不覆盖手动存档本身。
- 进入旅馆、回应早餐、跳入水洞及通往部分结局的决定前会留下关键节点；可在本次旅程中选择节点回溯，重新走出另一条路。回溯前的旅程会归档。
- 日记只记录有变化的发现与决定，以第一人称书写；重复往返相同地点不会堆出相同条目。每页 20 则，可回看且不会推进剧情。
- 重新开始会归档上一段旅程，包括未完成的旅程与已达成的结局；旧旅程供回看，不能从中恢复或重选。
- 旧版逐节点记录可直接读取并凝练成日记，同时保留当前游戏状态；下一次保存时写为新版格式。建议升级前自行保留重要的浏览器或应用数据，因为新版日记不再保存每个节点的完整原文。
- 记录保存在本机浏览器或桌面应用的本地存储中。浏览器与桌面版分别保存，预览地址的域名或端口不同也会分别保存；清除对应站点或应用数据会删除记录。目前没有云同步或导入导出。
- 读取失败时保留原数据；保存失败或检测到其他窗口已经更新时会显示提示并停止覆盖。极短时间内多窗口同时写入仍存在竞争风险，当前请在一个窗口内继续同一进度。

## 启动

在 VS Code 中打开本文件所在的 game 文件夹，再打开终端。

浏览器预览：

```powershell
npm.cmd run dev
```

打开终端显示的地址，默认是 http://localhost:1420 。

桌面窗口预览：

```powershell
npm.cmd run tauri dev
```

两种模式分别启动即可；若浏览器预览已占用 1420 端口，先在原终端按 Ctrl+C，再启动桌面模式。

检查与构建：

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run tauri build
```

剧情规则检查使用 Node.js 自带测试工具，需要 Node.js 22.18 或更新版本；当前开发环境为 Node.js 24。

`npm.cmd run tauri build` 会生成 Windows NSIS 安装程序。已经导出的 0.1.0 试玩版位于 `release/`（安装包约 8.6MB、便携包约 8.8MB，均含 28 张场景图），这个目录不会提交到 Git；正式发布时将其中的 setup、便携 zip 与 SHA256SUMS 作为 GitHub Release 附件上传。2026-09-24 的旧包已归档在 `release/archive-0.1.0-2026-09-24/`。安装程序未做商业代码签名，Windows 可能显示“未知发布者”或 SmartScreen 拦截；本地启动时选择“更多信息 → 仍要运行”，正式发布前可再考虑签名。

## 常用文件

项目级 Codex 配置、八个子 agent 的职责与协作方式见 [agent 配置说明](.codex/README.md)。新开发任务的长期依据见 [项目上下文](docs/项目上下文.md)，复杂任务可使用 [任务模板](docs/任务模板.md) 记录进展。

| 文件 | 作用 |
| --- | --- |
| src/story/opening.ts | 开场文字和每个选项去往哪里；以后改剧情先看这里 |
| src/story/items.ts | 物品名称、描述以及查看条件 |
| src/game/state.ts | 本次探索的初始状态、持有物品与已知线索 |
| src/game/engine.ts | 执行选择、读取场景和查看物品的规则 |
| src/game/records.ts | 日记归档、自动保存、旧版记录转换和读取检查 |
| src/game/diary.ts | 第一人称日记内容与去重规则 |
| src/game/cordPuzzle.ts | 衣柜绳端交换与解开条件 |
| src/ui/debrisPuzzle.ts | 碎木解谜弹窗与点击交互 |
| src/ui/cordPuzzle.ts | 衣柜绳线弹窗、拖动与键盘交互 |
| src/main.ts | 把故事显示出来，并响应按钮点击 |
| src/styles.css | 控制字号、颜色、间距及小屏幕布局 |
| src/ui/sceneArt.ts | 剧情节点与场景图、画面描述、色调的对应关系 |
| src/ui/scenePresentation.ts | 地点、调查特写与行动分组，物件在画中的位置与可点范围 |
| src/ui/sceneView.ts、sceneView.css | 场景舞台：换景淡入、画中可点物件、边缘出口、浮现旁白与选项 |
| src/ui/sceneLayout.ts | 决定每组行动显示为画中物件、边缘出口还是文字选项，以及旁白放在哪一侧 |
| src/ui/sceneNarration.ts | 保留完整正文的浮字分段 |
| public/scenes/ | 随游戏打包的静态场景图 |
| index.html | 页面入口和场景图容器 |

场景图存放于项目本地，绳阵和局部解谜仍由本地代码绘制；字体使用系统字体，运行时无外部图片或字体下载。正文为原设计的开场改编，可继续调整。

每轮改动见 [开发记录](docs/开发记录.md)。每一步修改前的源码备份位于 docs/checkpoints/，最新的是 step-16-before.zip。
